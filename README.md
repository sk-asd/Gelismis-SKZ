# SKZ - DEVZONES GEREKLİDİR!

Süreli kz eklentisidir komutçular için kolaylık sağlar.

## Kurulum

• Eklentiyi indirin.

• İndirdiğiniz dosyaları panelinizde veya FTPnizde addons/sourcemod/plugins klasörüne atın.

• Haritayı tekrardan açın.

### Oyun içi kurulum

• !zones yazın karşınıza bir menü gelecek ordan **Create Zones** e  tıklayın.

• KZnin bitişine bir bölge çizin ve ismini **SureliKZ** koyun.

• Eklenti Hazır!

# Komutlar

sm_skz - SKZ menüsünü gösterir.<br/>
sm_skz0 - SKZ yi sıfırlar.

# Ayarlar (cfg/Plugin_Merkezi/phiso_skz)

sm_skz_flag = Komutçu harici hangi yetki bayrağı skz menüsünü açabilsin?<br/>
sm_skz0_flag = Komutçu harici hangi yetki bayrağı skz sıfırlayabilsin?
